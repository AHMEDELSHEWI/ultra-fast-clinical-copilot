12. CORRECTING A WRONG MEASUREMENT
Keep this process very simple.
Example:
First measurement:
BP 90/60
Later the doctor checks the machine and realizes there was a problem.
The doctor changes the current BP to:
120/80
The system must then:
1. Use 120/80 as the current BP
2. Stop using 90/60 in current calculations
3. Recalculate relevant scores
4. Recalculate relevant warnings
5. Update the clinical reasoning
6. Update the documentation
7. Keep a simple record that the earlier measurement was corrected
The doctor should not need to understand technical database terminology.
Use simple wording such as:
CORRECT MEASUREMENT
or:
REMOVE FROM CURRENT CALCULATIONS
Do NOT use the word:
"Invalidate"
anywhere in the user interface.
