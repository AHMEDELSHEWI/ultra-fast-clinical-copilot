# Ultra Fast Clinical Copilot

Current release: **V1.0.5**

V1.0.5 adds automatic multilingual dictation with no visible language selector. The clinician starts recording directly; supported spoken languages and dialects may be mixed, and the application converts the captured speech into an English clinical transcript for clinician review.

## Entry points

- `index.html`: current GitHub Pages release, V1.0.5
- `v1.0.5.html`: preserved V1.0.5 entry point
- `v1.0.4.html`: preserved previous release

## Important operating notes

- Open the application over HTTPS in a current Chrome browser and allow microphone access.
- The first voice use downloads the multilingual browser model and can take longer than later uses.
- Speech recognition and translation can make clinically important errors. A clinician must review and correct all generated text before use.
- Do not use this software for real-patient care without institutional clinical, privacy, security, and regulatory validation.
